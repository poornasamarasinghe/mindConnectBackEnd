# 🧠 MindConnect
### Backend API – AI-Powered Mental Wellness Platform

MindConnect is an AI-powered mental wellness platform designed to provide personalized emotional support and guidance.

The platform aims to help users better understand and manage their mental well-being through intelligent tools and digital resources.

This repository contains the backend implementation responsible for supporting the application's server-side functionality.

## ✨ Project Overview

The backend is organized into separate modules to maintain a structured and maintainable application architecture.

### Core Backend Components

- API management.
- Service-layer organization.
- Database-related functionality.
- Reusable utility components.
- Server-side application logic.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| PHP | Backend development |

### Directory Responsibilities

**API**
- Organizes API-related functionality.
- Handles communication between the client and backend.

**Database**
- Contains database-related components.
- Supports application data management.

**Services**
- Organizes application service logic.
- Separates business operations from other components.

**Utilities**
- Contains reusable helper functions and supporting components.

## ⚙️ Getting Started

### Prerequisites

- PHP
- Composer
- Configured database environment

### 1. Clone the repository

```bash
git clone https://github.com/poornasamarasinghe/mindConnectBackEnd.git
```

### 2. Navigate to the project

```bash
cd mindConnectBackEnd
```

### 3. Install dependencies

```bash
composer install
```

### 4. Configure the database

Configure the database connection according to the project's database configuration.

### 5. Run the application

Start the application using the appropriate PHP server or development environment configured for the project.

MindConnect aims to combine technology and intelligent digital solutions to make mental wellness support more accessible and personalized.
